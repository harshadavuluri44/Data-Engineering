RDD creation

from pyspark.sql import SparkSession

spark = SparkSession.builder.appName('rdd').getOrCreate()

data = [('user1',9), ('user2',5), ('user2',7)]

rdd = spark.sparkContext.parallelize(data)

print(rdd.collect()) :- [('user1', 9), ('user2', 5), ('user2', 7)]
----------------------------------------------------------------------------------------------------

groupByKey() in RDD

What it does: Groups all values having same key into single collection (Iterable) across the cluster

grouped = rdd.groupByKey().mapValues(list)

print(grouped.collect()) :-  [('user1', [9]), ('user2', [5,7])]

Shuffling occurs across the nodes
----------------------------------------------------------------------------------------------------

reduceByKey() in RDD

Aggregates/ reduces the values for each key using a given function

It combines values locally with each partition before Shuffling

reduced = rdd.reduceByKey(lambda x, y: x+y)

print(reduced.collect()) :- [('user1', 9), ('user2', 12)]

Reduces shuffle data size bcz of local aggregation first.
----------------------------------------------------------------------------------------------------

DIFFERENCE BETWEEN groupByKey() and reduceByKey()

* groupByKey() shuffles data across all nodes
* reduceByKey() aggregates local first and then shuffles

IMPORTANT :- WE SHOULD NOT APPLY FUNCTIONS ON DATAFRAME,
                        WHICH WE IMPORT FROM pyspark.sql.functions (col, rank, avg, etc.,)
---------------------------------------------------------------------------------------------

Load data from file into df

df = spark.read.format('parquet').load(file_path)
df = spark.read.csv(file_path, header=True, inferSchema=True)

header = True -> df acknowledges first row as column names
inferSchema = True -> df acknowledges the data types of column
---------------------------------------------------------------------------------------------

Load data from delta table into df

df = spark.read.table('table_name')
df = spark.read.format('delta').load(table_storage_location)

table_storage_location :- s3 location which has delta log.
----------------------------------------------------------------------------------------------

Write data from df to delta table or delta location

df.write.format('delta').mode('overwrite').saveAsTable('table_name')
df.write.format('delta').mode('overwrite').save(table_storage_location)
df.write.format('parquet').mode('overwrite').save(file_path)

---------------------------------------------------------------------------------------------

df.show(n,truncate=False)

n (default = 20) -> shows first n rows of dataframe in console
truncate = False -> Prints full value eventhough value has more than 20 words
---------------------------------------------------------------------------------------------

df.printSchema() -> prints all col_names, data type, nullable=True/False in the console
df.schema -> Returns StructType() with all the details as a python variable

Use df.schema to detect schema mismatch between existing table and newly arrived data

True -> Column in df can contain null values, vice versa
------------------------------------------------------------------------------------------------

df.count() -> returns number of rows in df
------------------------------------------------------------------------------------------------

df.select().show() -> gives a dataframe
----------------------------------------------------------------------------------------------

df.collect() -> returns a python LIST with each element as each row in df
----------------------------------------------------------------------------------------------

We can convert row in LIST formed by df.collect() into Dictionary by  row.asDict()
[Dont apply .asDict() on List directly]
----------------------------------------------------------------------------------------------

df.columns -> returns a Python LIST with column names as elements
----------------------------------------------------------------------------------------------

df.filter(df['age']>40).show()
df.filter(df['age']>40 & df['salary']>35000).show()

In pyspark - Python's and , or not allowed - Instead use & , |
----------------------------------------------------------------------------------------------

df.withColumnRenamed('col_name','new_col_name').show()
---------------------------------------------------------------------------------------------

To find mean of one column

df.select(avg('col_name').alias('col_name')).show() -> returns df with 1 column and 1 row

To find mean of all columns

col_list = df.columns

df.select([avg(i).alias(i) for i in col_list]).show() -> returns df with all columns and 1 row
-----------------------------------------------------------------------------------------------

JOIN on single and multiple columns

df_joined = df_1.join(df_2, on='col_1', how='inner')
df_joined = df_1.join(df_2, on=['col_1','col_3'], how='inner')

join using different columns

df_joined = df_1.join(df_2, df_1.col_1=df_2.col_4, how='inner')
-----------------------------------------------------------------------------------------------

df_1.union(df_2).show()  -  Combines both df's with duplicate rows

NOTE :- df_1 and df_2 should have same columns and data types
----------------------------------------------------------------------------------------------

partitionBy() is used for physcially organizing data in disk/ file/ file_path
groupBy() is used for logically grouping data in dataframe
----------------------------------------------------------------------------------------------

PIVOT :- The distinct values in pivot_column becomes columns

df.groupBy('student').pivot('subject').agg(sum('score'))

EXPLANATION :- .groupBy() converts multiple rows of one student into one row/ student
               .pivot() converts all subjects into columns
               .agg(sum('score')) [mandatory with pivot]
